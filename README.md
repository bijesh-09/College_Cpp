# College_Cpp

Welcome to the **College_Cpp** repository! 👋

This repository contains all the C++ programs I (@bijesh-09) have written throughout my college semester. It serves as a comprehensive archive of my journey learning and practicing C++ as part of my coursework. The programs cover a wide range of fundamental and advanced topics encountered during the semester.

---

## 📚 Contents

- **Basic Syntax and Input/Output**
- **Control Structures**
  - If-else statements, switch-case, loops (for, while, do-while)
- **Functions and Recursion**
- **Arrays and Strings**
- **Pointers and Dynamic Memory**
- **Object-Oriented Programming**
  - Classes, objects, inheritance, polymorphism, encapsulation, and abstraction
- **File Handling**
- **Miscellaneous Programs**
  - Practice problems, assignments, and coding exercises

## 🚀 How to Use

1. **Clone the Repository:**
    ```bash
    git clone https://github.com/bijesh-09/College_Cpp.git
    ```
2. **Navigate to a Topic or Program:**
    ```bash
    cd College_Cpp/basics
    ```
3. **Compile and Run:**
    ```bash
    g++ program_name.cpp -o program
    ./program
    ```
